# BWB-BLI-UAV

## Aerodynamic Design, Optimization and CFD Analysis of a Blended-Wing-Body UAV

This repository documents the design and aerodynamic analysis of **CHARON**, a Blended-Wing-Body (BWB) unmanned aerial vehicle developed as part of my undergraduate thesis at the Hellenic Air Force Academy.

The project investigates the aerodynamic design of a compact flying-wing configuration and the integration of an embedded Electric Ducted Fan (EDF) propulsion system using **Boundary Layer Ingestion (BLI)**.

## Project Objectives

The main objectives of the project were:

- Develop and optimize the aerodynamic configuration of a BWB UAV.
- Generate and evaluate modified airfoil geometries.
- Integrate an embedded EDF propulsion system using Boundary Layer Ingestion.
- Perform aerodynamic analysis using low-order and CFD methods.
- Evaluate aerodynamic efficiency, stability and longitudinal trim.
- Compare numerical predictions obtained using different aerodynamic analysis methods.

## Repository Structure

- `optimization/` — aerodynamic optimization and airfoil generation
- `geometry/` — aircraft geometry and CAD development
- `propulsion/` — EDF integration and Boundary Layer Ingestion
- `cfd/` — OpenFOAM CFD simulations and post-processing
- `results/` — aerodynamic, CFD and stability results
- `figures/` — selected project visualizations
- `docs/` — technical documentation and methodology
